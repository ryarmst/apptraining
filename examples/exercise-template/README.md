# Sample Exercise

## Purpose

Demonstrate the required structure for a training lab and the platform task tracking flow.

## Topic

General application security training exercise template.

## Architecture

This lab is a Node.js and Express application that listens on port 8080. It exposes a basic health endpoint at `/api/check` and uses `check-completion.sh` to report task completions to the platform callback API.

## Candidate Flow

Candidates interact with the web application, identify the intended task conditions, and trigger completion events for each documented goal.

## Operational Notes

Copy this directory when starting a new lab. Replace the sample metadata, challenge documentation, routes, and completion checks with lab-specific content.
